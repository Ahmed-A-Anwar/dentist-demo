# Bright Smile Dental: Demo Site

Sample one-page website for a dental clinic.

## Stack
- HTML, CSS, JavaScript
- No frameworks
- Google Fonts: Playfair Display, Inter

## Features
- Mobile first layout
- Accessible: skip link, labels, focus styles
- Contact form
- Responsive at 375, 768, 1440px

## Note
All business details are placeholders. Phone, address, hours, and history are sample content.

## Run locally
Open `index.html` in a browser.
